R.M. Gurukul Bal Vidya Mandir — Website Demo
================================================

Files
- index.html: responsive bilingual website demo.
- school-logo.svg: vector logo used in the website.

Preview
1. Open index.html in a browser.
2. Internet is not required for this basic demo.

Important limitations
- Admission form currently displays a demo confirmation in the browser only. It does not send/store student information.
- Result search is a demo; no real student marks/results are stored.
- Replace contact placeholders and sample notices with verified school information before publishing.
- For real admissions/results/admin login, connect a secure backend and restrict access to student data.

Free publishing with GitHub Pages
1. Create/sign in to a GitHub account.
2. Upload the files to a public repository.
3. Open repository Settings -> Pages.
4. Under Build and deployment choose Deploy from a branch, select main and /(root), then Save.
5. Wait for deployment. GitHub will show the public site URL in Settings -> Pages.
6. Test the site on a phone and check all links.

Privacy and safety
Do not publish children's personal information, phone numbers, dates of birth, marksheets, or photos without appropriate school/parental permission. Use a protected admin system for private student data.
